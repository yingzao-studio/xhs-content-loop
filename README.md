# 小红书存量资料闭环 Skill

基于已有文档、图片、视频与参考资料，完成：

素材盘点 → 账号定位 → 选题排期 → 内容制作 →
发布准备 → 数据复盘 → 下一轮优化。

## 使用

将本仓库放入 Codex 的个人技能目录，文件夹命名为
`xhs-content-loop`。

调用示例：

> 使用 $xhs-content-loop，盘点指定资料目录，
> 制定 7 天小红书计划，完成第一篇可发布内容包。

## 文件

- SKILL.md：技能入口和执行流程。
- references/workflow.md：记录字段与验收标准。

本仓库不包含私人素材、登录凭据或账号数据。
发布与互动操作需要有对应授权。
实际能力取决于当前环境提供的工具。
